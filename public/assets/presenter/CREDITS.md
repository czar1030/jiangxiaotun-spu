# 江小豚讲解形象

讲解区直接加载 ../jiangxiaotun-v5/reception.svg 的定稿角色，复用原有柔和动作骨架。角色原始素材、改编署名及 CC BY-NC-SA 4.0 许可沿用 ../jiangxiaotun-v5/CREDITS.md。

mouth-small/open/round.webp 仅在原画嘴部的32×28像素局部增加小幅开口；停止或暂停时恢复原图，脸型、眼睛、头发、服装及尾鳍均沿用原素材。

face-serious/concerned.webp 从同一原画头部生成，仅修改眉部局部像素，保留脸型、眼睛、发型和透明轮廓。原图与对比图保存在 qa/voice/presenter-brow-comparison.png，生成脚本为 scripts/prepare-presenter-expressions.py。许可与原角色素材一致。

当前为二维原画驱动的讲解角色，不是三维模型。最初的程序几何模型已被用户否定并从运行时撤下，历史源码仅留在 qa/voice/rejected-procedural-avatar.mjs。
