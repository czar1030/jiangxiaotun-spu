## 快速运行

安装 Node.js 20 或以上，在项目目录执行 `npm start`，访问 http://127.0.0.1:3210 。无需密钥即可体验资料直答和页面功能。收藏和对话分别保存在每位访问者自己的浏览器。

面向 SAIG 线上赛的可运行网页。使用五份原始材料，支持武汉介绍、社区介绍、旅游规划、SPU 与 SAIG 赛事咨询。现有角色为按用户指定方向重新绘制的江小豚「楚风灵豚」矢量版。

## 打开作品

“认识武汉”从“来武汉，赴一场江湖”进入四幕城市故事：诗意江湖、敢为人先、热气人间、向新而生。实景影像随阅读交叉淡入，可通过章节入口快速跳读；江小豚会回应当前篇章，“慢一点，陪我看看”可暂停流金微光。故事后可继续收藏景点、翻看图鉴或打开旅行定制，保留原有招呼和待机动作。文史资料与影像来源分别链接；减少动态效果设置下关闭连续动画。

本地体验升级：保留原有荆楚主场景，“把江城，藏进你的喜欢”实景收藏画卷仅在“规划我的旅行”中显示。“认识武汉”以四幕城市故事和文化图鉴为主。六处风景可预览照片与简介，收藏后可带入旅行规划；预览不会自动发送 AI 请求。旅行对话中画卷收为可展开的工具栏，不遮挡回答。

“探索 SPU 社区”另设深海蓝、青蓝微光与少量青金点缀的专属共创画卷，可切换 Mark 印文物卡片、创始团队与智民里三个篇章，并进入对应故事及参与咨询。“了解 SAIG”设红蓝对阵的任务画卷，可切换四项各 25 分的赛题、查看演示思路、向小豚提问并前往官方报名入口。两个主题画卷仅在各自概览显示，不挤占对话区域；图片沿用已有官方产品、报道、赛事角色素材，支持键盘切换与减少动态效果设置。

“人和 AI，一起把事情做成”区域内整合青年寄语与参与邀请：历史寄语“早晨八九点钟的太阳”使用完整引号，标注讲话时间及文献，以纯文字呈现；下方独立呈现社区原创宣言“不是‘优等生’，也没关系”，保留学习 AI、创作与回馈社会的介绍及参与咨询入口。

画卷可切换晴光、听雨、落雪，照片光影与雨雪细节随之变化；对话里描述雨雪时场景也会跟随变化。它是情境预览，不是实时天气服务。雨雪建议优先室内、休息与短距离接驳，不主动安排轮渡。

点击“记住我的喜欢”可确认保存节奏、兴趣、住宿区域与同行偏好，存于当前浏览器；发送问题时作为默认条件提供给 AI，本次新条件优先。设置中可修改或清除。江小豚会轻轻朝当前关注的景点卡片转头，原有招呼、地图、望远和社区动作保留。

生成的逐日行程支持拖动或上下箭头调整当日顺序、“今天有点累”删减一处游览、恢复原方案、AI 复核与保存 PNG 旅行卡。重排后按已有静态站序重算交通；时间槽、价格和开放预约仍需复核，不能据此承诺实时可行。手账修改和原方案会随对话保存在本机。

画卷中的四步引导连接城市发现、旅行、社区与 SAIG：可以把收藏的地方带进旅行，再写下自己的接待员特色创意并带入赛事介绍。收藏仅存于当前浏览器；参赛建议始终保留赛事规定的四项功能。

当前电脑已安装 Node.js 20，不需要安装 npm 依赖。

## 江城视觉升级

首页采用楚青、玉白与暖金，加入黄鹤楼、大桥和江城天际线的原创 SVG 线稿。江小豚使用提供形象的透明背景版本，配合轻微浮动、水纹与指针视差。导航滑动、服务切换、弹窗进退和新消息出现使用统一缓动；系统开启“减少动态效果”时自动停用装饰动画。

第 5 版保留参考素材的脸型、眼睛轮廓、表情和身体比例，仅调整眼睛 / 瞳孔配色，并重新绘制发型、整套衣服和尾鳍。琥珀黄圆润短发、侧分斜刘海与呆毛，配青玉米白荆楚风交领服装、楚凤水纹和黄鹤簪；背面单独绘制后领、腰结与裙褶。耳鳍重绘为短小圆润的蓝灰鳍面，根部藏入头发并随表情调整角度，头部与衣领直接相接，无可见脖颈，小腿使用连续肤色层接入裙摆。尾巴改为蓝灰色长江江豚形态，具有平滑尾柄及水平展开的尾鳍，不再使用参考角色尾巴。脸部位图和新矢量图层合成，输出 PNG / WebP。首页、侧栏、聊天头像和四情绪保持统一，支持眨眼与点击欢迎；`/mascot.html` 提供三视图与透明图下载。

署名保留上善无形、ZipZipPipe、YunYueSama、xiaoweigen、Cayhaze。改编素材按 CC BY-NC-SA 4.0 共享，详情见 `public/assets/jiangxiaotun-v5/CREDITS.md`；历史原始素材和许可仍保留在 v2。构建：`python -X utf8 scripts/build_mascot_v5.py`（Pillow、resvg-py），未调用绘图 API。构建会核验主脸的 16,260 个非蓝色像素与原图一致；眼睛形状不重画。服装为现代荆楚风创作，不作特定朝代复原宣称。

网页正式采用定稿素材，聊天区提供完整姿态卡片，侧栏与每条回答头像同步表情。服务端返回 `emotion`（neutral / happy / thinking / serious / worried），在线模型按回复意图选择；资料直答、旧聊天和缺少该字段的兼容模型使用同一套内容判断。等待回答统一显示思考；取消、超时或接口异常显示关切。表情素材预加载并防止旧的加载结果覆盖新状态；中性状态保留眨眼，首页点击可张手欢迎；尊重系统减少动态效果设置。表情白名单与素材路径集中在 `public/mascot.mjs`，不接受模型生成的图片 URL。

电脑与手机使用分别调整的首页布局，聊天和旅游规划功能继续使用原有资料与 API。标题字体为本地加载的 Noto Serif SC 字符子集，许可证见 `public/assets/NotoSerifSC-OFL.txt`；不依赖访客访问外部字体服务。

### 长行程与接口接收

流式接口按 SSE 事件即时解析，只保留正文和当前事件，不再把所有协议包装累计到原先的 1.5 MB 限额。支持跨网络分块的 UTF-8、CRLF、多行 data、完成事件去重、JSON 兼容响应；明确识别长度截断、未完成状态和连接提前结束。正文上限、单事件上限及总网络数据上限分别控制，不输出服务商诊断或密钥。

保留现有服务地址与模型。Responses 请求设置 `max_output_tokens`，Chat 请求设置 `max_completion_tokens`；通常回答最多 12000 tokens，总览 7000 tokens，每段 10000 tokens。截断或格式错误至多重试一次，重新生成完整 JSON；认证失败与额度限流不自动重试。

确认具体天数后，6–30 天行程先生成全程片区、条件与预算蓝图，再按最多 4 天一段、最多 2 个并发调用展开，按原日序校验合并。不重复累加各段预算，合并后再计算地铁与轮渡参考。1–5 天通常单次生成。若只选择时间段，先按范围推荐片区、可选玩法、住宿周边及交通；最后再可选邀请补充精确天数。浏览器单独传递上一份完整 AI 行程，避免长行程被消息文本限额截断；指定某天下雨的修改只替换该天，其他天保持原安排。

若某段失败，保留成功日期并明确列出缺失日期，不用静态模板冒充完整 AI 行程；后续“补齐缺失天数”仅生成缺失部分。单次上游调用最多 95 秒，全请求最多 300 秒，浏览器等待上限 315 秒，可随时取消。完全没有可用结果时仍使用明确标注的资料直答。

真实 8 天接口验收脚本为 `node scripts/check-ai-generation.mjs`，会使用已配置接口额度。结果保存在本机 `qa/ai-generation/`；合并逻辑另有 30 天自动测试，不将模拟测试当作真实接口测试。

## AI 配置

密钥只存放于本机 `.env` 或托管服务私密环境变量。仓库不包含用户的真实密钥，HTTP 服务不会提供它。

本接口实际验证可工作的调用组合为：

```dotenv
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=自行配置，不要写入前端
AI_MODEL=deepseek-flash
AI_API_STYLE=chat
PORT=3210
HOST=127.0.0.1
```

当前采用 DeepSeek 官方 Chat Completions 流式接口，使用官方返回的 Flash 模型标识 `deepseek-flash`。服务端收集并解析流式内容后向网页返回答案，禁用额外思考模式，使用 DeepSeek 的 `max_tokens` 参数限制输出。其他兼容服务仍支持 `responses` 和 `chat` 两种接口格式。

2026-11-16 已通过真实密钥的模型列表检查及最小生成请求。该验证不代表已对所有语言或长行程逐项进行付费验收。不会自动轮询或切换其他收费模型。

修改 `.env` 后需要重启本地服务。生产部署默认关闭在线 AI，启用条件见 [部署说明](docs/DEPLOYMENT.md)。访客使用托管网页时由后端调用私密密钥；下载源码独立运行不会自动获得作者的密钥。

### 多语言接待

首页江小豚新增分阶段待机表演：页面内约 12 秒无操作时轻轻张望，60 秒时抬右手托腮并半垂眼睑，120 秒时进入轻微打盹。托腮使用错峰抬臂、转腕、歪头的 2.7 秒过渡，配合呼吸、眨眼和江豚尾鳍摆动。鼠标移动、键盘输入、触摸或滚动都会唤醒；靠近角色时先自然放下手，再微笑挥手。悬停触发 5.2 秒挥手：增大肩与肘的摆幅，手腕随后摆动，头部轻轻歪向举起的右手。点击（或键盘激活、触屏轻点）触发独立的 6.2 秒“欢迎来武汉”迎接：复用定稿 happy.png 的开心眼睛、张嘴笑和双手张开姿态，分离双臂与头部做轻微张手、歪头和重心起伏。关节曲线以每秒 60 个姿态采样，肩、肘、腕、头部和尾巴各有延迟与跟随；点击打断挥手时从当前可见姿态衔接，并交叉淡入双手欢迎，欢迎形态期间隐藏挥手与原站姿腿部，避免肢体重影。鼠标停在角色上不移动也能正常进入待机。页面隐藏、角色离开视口或打开对话框时暂停待机计时；系统开启“减少动态效果”时不自动表演。待机气泡支持全部 16 种界面语言，不会发送聊天消息或调用模型。素材构建：`python -X utf8 scripts/build_mascot_idle.py`；静态关键姿态见 `qa/idle/poses.jpg`。
