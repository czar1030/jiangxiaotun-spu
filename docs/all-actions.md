# 江小豚整套动作细化

以已确认的招呼样片为表演基准，保留现有面孔、荆楚衣装、三个接待场景与 SAIG 的独立侧面造型。

- 招呼与欢迎：连续的肩袖、肘部和手掌轮廓，预备、转移重心、挥手、停留及收势分别编排；手指轻卷，头部、耳朵、呆毛、裙摆和系带延后跟随。
- 待机：倾听、转头、整理衣装和轻点头之间保留安静停顿，取消身体变换里第二套无关的呼吸振荡。
- 看地图与放大镜：同一条观察曲线驱动扫视、手持镜片和躯干。头部领先约 0.18 秒，肩膀滞后约 0.16 秒；镜片沿纸面作两次轻缓弧线观察，短暂停留后归位。
- 踮脚望远：保留取镜、抬镜、伸镜、踮脚、左右观察与收镜。观察方向与上半身重心联动；落脚时轻微屈膝缓冲，呆毛随后归位，手与望远镜继续共享精确锚点。
- 电脑：只保留开合。打开前先注意屏幕，打开后低头专注，合上时抬头，收好后肩膀放松。空着的手留在键盘外，电脑从实际显示的托举手定位。
- 托腮、揉眼与休息：手沿身体外侧的弧线靠近脸，闭眼后才接触；揉眼降为约每秒一次、极小幅度。先落手，再恢复道具，保留可中断的衔接。
- SAIG：保留独立完整绘制的进场帧、蓝方挑战、红方抱胸与完成姿势后召唤回声的顺序。竞技姿势的肩颈、胸口和重心连成整体，拓宽蓝方抬臂的衣料过渡，避免局部过紧。

连续袖片的求解器在动作与渲染模块中使用相同版本，共享每帧缓存，避免为同一姿势重复构建衣袖。
