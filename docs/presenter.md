# 江小豚讲解功能

四区的首页文案下方及顶部都有“让小豚讲解”。在当前网站打开面对面讲解区，首次进入自动介绍当前主题，可暂停、继续、停止、切换四个主题和输入问题。再次返回保留本页会话，不重复打断式开场；可主动点击“听本区开场”。关闭讲解区立即停止声音与当前问答，原网站会话保留。讲解会话按四区分别保存在本页内存中，刷新后重置；声音、语速、自动朗读及问答方式保存在本机。

## 形象与声音约束

用户否定了第一版程序几何三维模型，认为完全不像江小豚。当前运行时改为直接加载已认可的 `public/assets/jiangxiaotun-v5/reception.svg`，沿用既有原画、柔和动作骨架和脸部表情。仅嘴部局部增加开口。不要把当前二维原画驱动形象说成真正三维模型，也不要恢复被拒绝的模型。真正三维化尚未完成。

声音目标是“动漫少女帝王音”：年轻、清澈、沉稳、威严、有底气；拒绝机械播报、过萌、撒娇、夹嗓子和浑浊音色。用户于2026-11-12认可 Xiaoyi Neural、音高 -12Hz 的音色，随后指出“音色没有太大问题，就说话有气无力的像个僵尸”。因此当前保留音色与音高，将基础语速从 -6% 调至 +4%，发声力度 +12%，开场与试听重新合成，措辞和断句更利落。浏览器原有轻微低中频削减、清晰度增强保持不变。不要把旧的慢速文件继续当作默认，也不擅自恢复此前被拒绝的播报声或高音萌声。用户随后明确确认“很好，不错”“声音定了，剩下继续”，因此音色、音高、节奏和发声力度均以这版锁定，不再擅自调整。没有声优录音、声线克隆或专门训练的动漫模型。

## 知识与事实

继续使用原 `/api/chat`、五份已索引原始资料、图文资料和赛事规则快照进行检索问答。`presentation:true` 只增加适合口头讲解的简洁表达要求，不更改事实和引用规则。讲解区独立选择“AI + 项目资料”或“资料直答”，默认AI；未配置AI时使用资料直答，不修改原站会话的模式。在线问答失败明确显示资料直答及原因。四区开场为人工整理的固定导览，不冒充实时生成结果。

每条回答与来源一起保存，长会话截断时保持对应。完整行程的安排依据、每日地点、交通、费用、预算和提醒均可展开并复制；旅行追问附带上一版完整行程。回答表格保留在侧栏，语音跳过表格结构。按回答展示项目图库中核实的地点图片和影像来源，舞台卡片可继续点选提问，推荐追问也随回答更新。

## 语音运行

固定四区开场和短试听已生成 MP3，首次点击直接播放；临时回答通过同源 `/api/presenter/speech` 请求服务器生成。默认在线 Microsoft neural speech，经 `edge-tts==7.3.1`，不需要 API key。只有用户手动选择时才使用本机 Windows 女声或浏览器音色；不会把失败的自然语音偷偷换成之前被拒绝的机械女声。

当前固定音频为 `*-imperial-v2.mp3`，记录见 `public/assets/presenter/voices/provenance-v2.json`，可运行 `node scripts/prepare-presenter-voices.mjs` 重建。旧文件及其原始认可记录保留用于对比。相同旅行开场从21.43秒缩短到19.39秒，平均电平提高约1dB，未出现削波；这只能验证节奏、电平与文件正常，用户已经试听并确认当前效果。

新电脑准备：

```powershell
python -m venv tools/voice-venv
tools/voice-venv/Scripts/python.exe -m pip install -r scripts/presenter-voice-requirements.txt
```

自然语音需要联网；本机 Windows 备用语音使用 `System.Speech`。服务端限制输入长度、并发进程与语音缓存，浏览器也缓存最近音频并提前准备下一段，重听不重复生成。关闭和切换会取消旧请求，避免旧声音晚到后串播。密钥不进入前端。当前只提供文字提问，没有接入麦克风识别。

动作包括开场挥手、思考托腮、倾听和讲解手势；开心沿用原有笑脸；认真和关心仅修改原画的少量眉部像素，眼睛、脸型、发型与其余像素保留，生成脚本为 `scripts/prepare-presenter-expressions.py`。讲解句子匹配卡片关键词时，高亮与掌心介绍手势联动。支持Web Audio时，嘴部小幅开合跟随真实音量，停顿时闭嘴；不支持时退回按播放状态驱动的近似嘴型，不是音素级口型同步。系统减少动态效果设置会关闭连续动作。切到后台自动暂停朗读。

验证：`npm test`；浏览器检查覆盖手机与桌面布局、实际音频播放、暂停/继续、跨主题知识库问答、切换主题及关闭清理。记录保存在 `qa/voice/`。
