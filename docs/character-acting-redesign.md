# 四模块动作重做（2026-10-29）

本轮依据用户提供的舞蹈、招呼及提裙摇摆参考，改动角色姿态和动作节奏。保留既定琥珀短发、脸部/眼形、荆楚服装、蓝灰江豚尾巴及各模块背景。没有调用绘图 API，也不把程序补间描述为逐帧手绘。

## 已接入首页的变化

- **认识武汉：** 分别设计倾身倾听、转头张望、整理衣装和轻点头。动作之间有完整停顿；头部与胸口同向配合，衣物跟随主动作，减少持续无意义的周期摆动。
- **通用招呼与欢迎：** 招呼按准备、抬手、两次招手、收手设计完整姿态。手沿身体外侧抬起，头/胸/重心配合；加入较圆润的专用招手掌形及指尖轻屈。欢迎双臂高低和展开时序略有差异，肘部弯曲，保留既定开心欢迎脸。
- **规划旅行：** 保留展开地图、放大镜查看、举单筒望远镜和踮脚。看图和望远时胸口、头部及重心与观察方向配合；扫视包含短暂停留，避免一直扫来扫去。手与道具保持共同坐标。
- **SPU 社区：** 保留端电脑、开合电脑的动作。低头阅读、轻微转向和短暂抬头回应组成有意图的表演，不恢复打字。回声的搭肩接触跟随新的躯干变形。
- **SAIG：** 保留入场时序、召唤、蓝方挑战和红方抱胸姿势。蓝方先略收重心再挑战，红方稍后从容回应；取消原先部分持续正弦摆动，以完整网格传递胸、头和手臂之间的运动，保持足底不动。回声和红方翅膀继续运行原有动画。

## 连接和变形

`character-acting.mjs` 保存全身姿态的有意图节拍及曲线；`body-space.mjs` 统一头、领口、袖子、手和道具所在的身体坐标系。新增连续腿部轮廓连接移动的裙摆与支撑鞋；胸部轻侧倾和屈膝不再与下身脱开。袖子的肩部弧线随抬手调整，手腕锚点不变。表情仍使用原本完整绘制的眼部/脸部，避免重叠瞳孔。

## 验证和复查

- `npm test`：86／86 通过。
- 继续验证地图与望远镜握持、电脑边界、肩膀接触、休息/揉眼恢复、30／60／120 Hz 稳定性及 SAIG 网格不翻面。
- 新增招手全程手掌避开脸部、完整姿态重置、重心和头部连续性、腿部轮廓接到移动裙摆且支撑鞋不移动的检查。

- 生产动作导出使用 `scripts/preview_fluid_motion.mjs`、`scripts/render_fluid_motion.py`；静态姿态使用现有旅行、社区和服装预览脚本。检查产物在 `qa/character-acting/` 与 `qa/motion-fluidity/`。

测试约束的是连接、安全距离和连续性；审美质量需结合正常速度和慢速画面查看，不能只凭测试数量或帧率认定动作自然。
