# 江小豚动作设计参考准则

用户优先要求动作流畅、自然、可爱和全身协调。约 60 FPS 是播放目标，不能作为动作质量已达标的证据。

## 观察与应用

1. **先设计全身关键姿势。** 舞蹈中手臂、肩线、躯干倾斜及头部倾斜形成同一个姿态；不能分别为每块身体添加互不相关的周期摆动。
2. **关键姿势必须读得懂。** 抱手、抬手、向外摊掌及左右换向在小尺寸下依旧明确。江小豚先用黑色剪影检查动作可读性，再完善服装。
3. **主动作和次要动作有层次。** 身体和手臂决定动作方向，头部、发梢及衣摆作适量跟随；固定相位延迟不能替代针对动作设计的跟随。
4. **移动身体必须考虑支撑。** 身体偏向哪边，支撑脚和髋部必须相应配合。镜头未拍全脚的参考不能用于证明具体足底接触，应另外设计完整脚步。
5. **手、前臂、袖口按姿势绘制。** 摊掌、握持及遮脸需要不同轮廓、朝向和遮挡；不能只将同一只正面手掌转到各个角度。
6. **头部参与动作但保持头身连接。** 头倾时脸、头发、耳朵、颈部遮挡和领口一起检查；保留江小豚无外露脖子的设定。
7. **节奏包含停顿。** 快速过渡后清楚保持姿势，再转换方向；不能所有部件始终用同一条缓动曲线移动，也不能通过延长插值把动作拖得软弱。
8. **轮廓变化要有因果。** 躯干轻压缩、衣袖折叠和发梢滞后必须回应动作；不要无意义地全身缩放或晃动来制造动感。
9. **手与脸的遮挡可以是有意表演。** 参考舞蹈中的手臂挡嘴是明确姿势。应区别于手臂错误地穿过脸，检查完整动作路径和前后层级。
10. **先验证一段完整表演再推广。** 以约 2–3 秒招呼动作验证：注意到人 → 重心准备 → 抬臂 → 招手 → 收手。保留既定形象、地图/望远镜、电脑开合、竞技姿势等产品要求。

## 验收顺序

静态关键姿势协调 → 慢速检查连接及遮挡 → 正常速度检查节奏 → 循环与中断检查 → 最后测量帧率和性能。测试通过、补间密度增加和渲染达到 60 FPS 均不等于审美验收通过。

本次仅分析参考并记录准则，没有据此修改网站动画，也没有宣称已达到参考质量。

## 补充：蓝发角色的轻蹲、提裙与摇摆参考

新增 GIF 为 240×320、27 帧、2.7 秒，每帧 100 ms（文件平均 10 FPS）。拆帧图为 `qa/reference-animation-analysis/bow-reference-frames.jpg`。实际动作包含轻微下沉、提裙和左右摇摆，不宜简单理解成只旋转头部的鞠躬。

- **身体是一整个体积。** 下沉时头、肩、腰和裙摆的位置相互配合；不能让头单独上下漂浮，也不能仅缩放整张角色代替下沉。
- **手和衣物之间有接触关系。** 提裙时手与裙侧共同运动。应用到江小豚的地图、望远镜和电脑：先确定接触点，再让手臂、肩部适应动作，不让道具各自飘动。
- **配件保持体积和连接。** 头饰跟随头部，发梢、裙边、尾巴在转向时变化；不能让配件与头部连接处脱开。可借鉴跟随节奏，不照搬长发或女仆装。
- **脚底与投影提供重量感。** 角色轻摆时仍能读出脚下支撑；江小豚在原地动作中保留支撑脚，踮脚时再按动作抬起足跟。
- **表情变化可以很少。** 该片段长时间闭眼，依然依靠姿势、节奏和轮廓表达情绪；不要用连续换表情弥补身体动作不足。
- **小动作需要可见但克制的幅度。** 主体下沉/侧倾应读得懂，头发和裙边负责细节；避免所有部位一同大幅弹动。

以上是成片观察；不能据此断言使用了逐帧手绘、3D、骨骼或某个具体软件。此次仍仅更新参考准则，未修改网站动作。
